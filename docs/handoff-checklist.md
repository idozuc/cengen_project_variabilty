# Handoff checklist

- Restore R and Python dependencies in clean environments.
- Copy example configurations and set external input paths.
- Verify SCE assays, metadata, stable IDs, and input checksum.
- Complete a one-cell-type clustering and BASiCS smoke run.
- Review convergence before interpreting HVG/LVG calls.
- Build and validate explorer assets before launching Streamlit.
- Confirm `rg '/Users/|/sci/|MY_R|entropy'` finds no active dependency.
- Confirm `data/` and `outputs/` contain no files intended for Git.
- Select an approved public license before making a GitHub repository public.
